# 超市（David-ShopCatalog）— Brotato 模組

## 安裝（只要 3 步）
1. 下載 [`release/David-ShopCatalog-0.6.4.zip`](release/David-ShopCatalog-0.6.4.zip)（點進去後按右上角的下載按鈕）。
2. **不用解壓縮**，直接把 zip 放進遊戲的 `mods` 資料夾。Epic 版在 `E:\Epic Games\Brotato\mods\`。
3. 重開遊戲。

如果 `mods` 資料夾裡有這個模組的舊版 zip，請先移走或刪除，避免兩版同時載入。

需求：Brotato 1.1.15.4（遊戲內建 ModLoader 6.3.0，不用另外安裝）。

## 原始碼
根目錄的 `.gd` 與 `manifest.json` 就是 zip 裡 `mods-unpacked/David-ShopCatalog/` 的內容。
